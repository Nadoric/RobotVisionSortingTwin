# 工业设备外观

场景继续使用 WPF 原生三维几何，外观组件集中在 `Simulation/TwinScene.Industrial.cs`。
应用图标位于 `Assets`，同时用于程序文件、窗口和标题区。

更新内容：

- 输送机：铝型材槽、横撑、调平脚、端部滚筒、轴承座、减速电机、散热筋及光电传感器。
- 视觉工位：龙门型材、工业相机壳体、镜头、条形灯、线缆与接线盒。
- 机器人：渐缩铸件外壳、关节减速机盖、法兰螺栓、外置软管及双吸盘末端。
- 控制站：落地柜、HMI、急停按钮、通风格栅、线槽及红黄绿三色灯。
- 料仓：箱沿、加强筋、脚轮和标牌，保持 A/B/C 与三种物料的颜色关系。
- 厂区：环氧地坪、步行通道、设备接触阴影、照明和网格式围护。
- 物料：圆形轴套使用真实空心网格；搬运高度按物料高度调整，使吸盘与工件接触更自然。

设备标识、命中选择、仿真固定步、逆解臂长和双向执行协议继续沿用。
静态构件和共享网格/材质冻结复用，运动层只更新机器人、物料、皮带标记与状态灯。
“聚焦设备”对机器人提高目标点，对输送线扩大取景距离，便于查看完整设备。

生成整体、较小窗口及设备近景：

```powershell
dotnet run --project tests/Verify.csproj -c Release -- --render artifacts/industrial-preview
```

输出包含 `sorting-twin-1560.png`、`sorting-twin-1100.png`，以及机器人、相机工位和输送线的近景。
